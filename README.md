## 📌 Descripción

Este repositorio reúne el material, guías, talleres y proyectos prácticos desarrollados para la asignatura **Estadística y Analítica de Datos** de la UPTC. El contenido abarca desde el análisis exploratorio de datos hasta el modelado estadístico e inferencial aplicado a problemas reales.

---

## 📁 Estructura del Repositorio

```text
Estadistica_Analitica_Datos_UPTC_2026-2/
│
├── data/               # Datasets y fuentes de datos utilizadas
├── documents/          # Guías y presentaciones
├── homework/           # Informes de entregables
├── notebooks/          # Jupyter Notebooks con análisis interactivos
```

## 🛠️ Tecnologías Utilizadas

- Lenguajes: Python / R

- Librerías principales:

  - pandas, numpy (Manipulación de datos)

  - matplotlib, seaborn (Visualización)

  - scipy, statsmodels, scikit-learn (Análisis estadístico y modelado)

  - Entornos: Jupyter Notebook / Google Colab / VS Code
